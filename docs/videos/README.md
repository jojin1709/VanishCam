# Demo videos

Drop your recordings here — the website picks them up automatically:

| File | Shown as |
|---|---|
| `hero.mp4` | the big main demo player on the home page |
| `clip-1.mp4` | first small clip (e.g. the "where did you get that" video) |
| `clip-2.mp4` | second small clip (e.g. install walkthrough) |
| `hero-poster.jpg` | optional thumbnail shown before the hero video plays |

Rules of thumb:

- **MP4 (H.264)** plays everywhere — export from CapCut/OBS as `MP4 · H.264 · 1080p`.
- Keep files **under ~25 MB** so the page loads fast; longer videos can be hosted on
  YouTube instead — replace the `<video>` block in `../index.html` with a YouTube iframe.
- Name them exactly as above (lowercase) or the page will keep showing
  "coming soon".
